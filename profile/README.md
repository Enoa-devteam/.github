# Enoa

### What if a conversation could build something?

**Conversation is the interface. Engineering is the goal.**

We're an open-source team exploring where **conversational AI meets coding agents** — how natural dialogue can lead to real engineering work, with code, tools, and results we can test and improve.

**好奇心是起点，实践是回答。**

我们希望对话不只停留在语言之中，而是连接工具、代码与真实的工程实践。

我们愿意提出假设、动手实验、验证结果，也愿意承认尚未找到答案。探索不必始于完整的方案；一个问题、一段代码，或一个不同的观点，就足以开始。

**Curious? Come explore with us.**  
**如果你也对此感到好奇，欢迎一起探索。**
