# Enoa

**CONVERSATION IS THE INTERFACE. ENGINEERING IS THE GOAL.**

Enoa is an open-source development team building **chatbots with practical engineering capabilities**.

Our vision is to bring **conversational AI and coding agents together**: combining natural dialogue and contextual understanding with tools, software development, and verifiable execution. We want AI assistants that go beyond answering questions — systems that can help turn human intentions into meaningful engineering work.

We believe this should be done **openly, reliably, and with clear boundaries between conversation, decisions, and actions**.

**Enoa 是一个致力于开发具备实际工程能力的聊天机器人的开源组织。** 我们希望将聊天机器人的自然交互与上下文理解能力，同 Coding Agent 的工具调用、代码开发和任务执行能力有机结合，让 AI 不仅能够回答问题，也能在可靠、可控、可验证的流程中协助完成实际工程工作。
