# Enoa

**BUILDING RELIABLE SOFTWARE, OPENLY.**

*Open-source AI systems, developer tools, and software infrastructure.*

Enoa is an independent open-source development initiative focused on building practical, extensible, and reliable software.

We explore how AI agents, interoperability, and developer tooling can work together — with an emphasis on local-first computing, predictable behavior, and open ecosystems.

**Enoa 是一个独立的开源开发项目组，致力于探索人工智能代理、软件基础设施与开发者工具。我们关注实际可用性、系统可靠性以及开放的技术生态。**

## Our Principles

- **Open by Design** — Favor transparent development, open interfaces, and reusable components.
- **Reliability First** — Make software testable, maintainable, and resilient to failure.
- **Efficiency Matters** — Build systems that remain useful under practical resource constraints.
- **Interoperability** — Reduce unnecessary boundaries between frameworks, tools, and ecosystems.
